## [0.2.0](https://github.com/impulseframework/bedrock/compare/v0.1.4...v0.2.0) (2026-11-24)


### ⚠ BREAKING CHANGES

* `bedrock check` and `bedrock render` refuse an application that declares `APP_<AUTH>_ADMINISTRATOR_PASSWORD`, and the rendered stack holds no password secret for a first administrator and grants no read of one. The first administrator is invited instead: the application needs an impulse release whose migrate command mails the invitation, it takes the declaration out, and its placement names the person's email address in `<auth>_administrator` for each environment. An environment already deployed with the generated password cannot release under this bedrock: the declaration can be neither kept nor removed there, so the environment is made again.
